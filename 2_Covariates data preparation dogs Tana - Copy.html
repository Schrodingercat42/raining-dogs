Create PCA-based urban indexes

Based on proportions of urban classes across the whole CUA, we calculate the principal component analysis to introduce index 1 and 2, corresponding to PC1 and 2, thus decreasing the number of future covariates for the model and avoiding collinearity between variables. It turns out that PC1 explains 60% of the variability, which is nice.

# Run PCA 
pca_result <- prcomp(urban_str_fkt_all[, c("p_green", "p_urban", "p_industrial", "p_water")], center = TRUE, scale. = TRUE)

# Explained variance; first two components
var_explained <- (pca_result$sdev^2) / sum(pca_result$sdev^2) * 100
var_explained[1:2]
[1] 61.04198 20.77710
scores <- predict(pca_result, newdata = urban_str_fkt_all[, c("p_green","p_urban","p_industrial","p_water")])

#we create "raw" form and scaled form of the index, for different purposes downstream
urban_str_fkt_all <- urban_str_fkt_all %>% 
  mutate(
    urban_index1 = scores[,1],
    urban_index2 = scores[,2],
    index1_s = scale(urban_index1),
    index2_s = scale(urban_index2))

# Save raw PCA scores for all fokontany
write.csv(urban_str_fkt_all, file = "urban_str_all_fkt.csv", row.names = FALSE)
